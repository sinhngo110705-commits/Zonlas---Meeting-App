05

Engineering Rules

01Design First. Khong code feature nao khi chua co design approve trong Figma. Designer la source of truth.
02Token-driven styling. Moi mau sac, spacing, font size phai dung design token — khong hardcode gia tri.
03TypeScript strict mode. Khong dung any. Type everything. PR khong pass lint thi khong merge.
04Mobile-first. Moi component duoc build mobile truoc, roi responsive len desktop.
05Performance budget. LCP < 2.5s, CLS < 0.1, FID < 100ms. Lighthouse score > 90 tren production.
06Branch strategy: main protected. Feature branch → PR → review → squash merge. Khong commit thang vao main.
07Document as you build. Moi component co Storybook story. Moi API endpoint co Swagger doc. Khong de no docs.
